# Demos

This directory contains runnable Taproot Assets SDK demos. Demos are intended
to show complete application flows against a local or configured `tapd`
instance, not just isolated code snippets.

## Available Demos

- [Remote Signing Coordinator](remote-signing-coordinator/README.md) - a
  regtest-ready Go and Next.js dashboard for reviewing and signing external
  Issuance requests with a software device powered by BDK-WASM.
